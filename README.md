# The Human Rewilding Clinic

A speculative course demo by Mere Cui for Simulations, Models, Twins. The fictional visit follows a removable contact insert and sleeve from a clinic fitting to a proposed window support.

Open `index.html` in a browser to run the self-contained demo. The water model compares a blocked and a working drain under shared assumptions. Its results describe the simulated assembly. Physical validation and measurements are pending.

The skin-contact figure is a secondary analysis of public participant S16 from [Mhuireach et al., 2022](https://link.springer.com/article/10.1186/s40793-022-00457-7) and the associated [Figshare dataset](https://doi.org/10.6084/m9.figshare.16655140). The control was a skin-to-skin transfer. N01 is a fictional source label used in the proposed design.

The embedded visual models and textures are from [Poly Haven](https://polyhaven.com/license) under CC0. The [Three.js](https://threejs.org/) MIT license is included in this repository.
